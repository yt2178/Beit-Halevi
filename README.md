## ✨ פיצ׳רים עיקריים למשתמש

### ⚡ ביצועים וטכנולוגיית Vanilla JS
- **טעינה מיידית ללא Frameworks:** בנוי ב-Vanilla JavaScript, HTML5 סמנטי ו-CSS3 מודולרי. ללא תלויות כבדות (React/Vue/Angular), מה שמבטיח מהירות תגובה שיא גם במכשירים חלשים ובגלישה סלולרית.
- **מצב כהה / בהיר (Dark & Light Mode):** מעבר חלק בין ערכת נושא יוקרתית כהה (כחול-נייבי מלכותי וזהב) לערכה בהירה, עם שמירת העדפת הגולש ב-`localStorage`.

### 📅 זמני היום, שבתות והלכה (Hebcal API)
- **זמנים דינמיים לפי מיקום ראש העין:** חישוב והצגה של עלות השחר, הנץ החמה, סוף זמן ק״ש (גר״א ומג״א), חצות היום, מנחה גדולה/קטנה, שקיעה וצאת הכוכבים.
- **זמני כניסת ויציאת שבתות ומועדים:** כולל פרשת השבוע, זמני הדלקת נרות ומוצאי שבת מעודכנים שבועית.
- **המרת תאריך עברי מדויק:** הצגת התאריך העברי השוטף בכל חלקי האתר.

### 🖼️ גלריית תמונות עשירה ועמידה לסינון (נטפרי / אתרוג)
- **100% נכסים מקומיים (Local Assets):** כל 135 התמונות ב-12 אלבומי הישיבה מאוחסנות ישירות בתוך המאגר המקומי (`assets/gallery/album-1/` עד `album-12/`). פתרון זה מעניק **חסינות מוחלטת מחסימות סינוני אתרוג/נטפרי** ומונע תמונות שבורות.
- **צפייה נוחה (Lightbox):** הגדלת תמונות במסך מלא, ניווט במקלדת, ומחוות החלקה במגע (Touch Swipe) במכשירים ניידים.
- **הורדת תמונות בודדות והורדת אלבום מלא (ZIP):** הורדה ישירה של תמונה באיכות מקורית, וכן מנגנון הורדה במקביל של כל תמונות האלבום כקובץ ארכיון ZIP מובנה ישירות בדפדפן באמצעות `JSZip` ו-`Promise.all`.
- **שיתוף ישיר לוואטסאפ (WhatsApp Share):** כפתור שיתוף מובנה לכל אלבום עם כותרת, תיאור וקישור ישיר.

### 📰 חדשות, הודעות ושיעורים
- **כרטיסיות ומודאל קריאה מלא:** תצוגה נקייה של עדכונים שוטפים מהישיבה עם תאריכים עבריים ולועזיים.
- **שיתוף ידיעות:** כפתור שיתוף מהיר לוואטסאפ עבור כל ידיעה.
- **תמיכה בעיצוב עשיר:** תמיכה ב-Markdown באמצעות `marked.js` עם הגנת XSS מלאה באמצעות `DOMPurify`.

### 🔔 התראות פוש (Web Push Notifications)
- **OneSignal Web Push:** תשתית לקבלת הודעות מתפרצות על שיעורים, שמחות ואירועים.
- **Fallback מובנה ל-Notification API:** מעבר שקוף למנגנון ההתראות המקומי של הדפדפן במידה ושירות צד שלישי אינו זמין.

## 📱 אפליקציה למכשיר (PWA) ומיתוג

האתר מוגדר כ-**Progressive Web App (PWA)** ברמה הגבוהה ביותר, ומאפשר לכל משתמש להתקין אותו כיישום עצמאי במסך הבית של הטלפון הנייד (Android / iPhone) או במחשב:

- **סמל ישיבה מלכותי וצבעוני:** מיתוג עשיר המבוסס על סמל הישיבה המקורי – גווני זהב חמים ומבריקים (`#e5a92a`), אבני רובי אדומות מודגשות (`#dc1c30`), כתר הישיבה ודפי הגמרא, על גבי מדליון יוקרתי עם טבעות זהב כפולות ורקע כחול-נייבי עמוק (`#0f172a`).
- **סמלים מתכווננים לאנדרואיד (Maskable Icons):** קובצי `icon-maskable-512x512.png` ו-`icon-maskable-192x192.png` מותאמים עם שולי בטיחות (Safe Zone) של 80%, המונעים חיתוך או עיוות של הלוגו בכל ממשק הפעלה (סמסונג, גוגל פיקסל, שיאומי וכו').
- **תמיכה מלאה ב-iOS (Apple Touch Icon):** קובץ ייעודי `apple-touch-icon.png` (180x180 פיקסלים) לתצוגה יוקרתית במסך הבית של מכשירי iPhone ו-iPad.
- **חבילת `favicon.ico` רב-שכבתית (Multi-Resolution):** קובץ אייקון מודרני המכיל שכבות 16x16, 32x32, 48x48 ו-64x64 לתצוגה חדה וצבעונית בלשוניות הדפדפן ובתוצאות החיפוש של Google.
- **פעולה מלאה ללא חיבור לאינטרנט (Offline Cache):** שירות Service Worker ייעודי (`sw.js` גרסה `v57`) שומר את כל דפי האתר, הסגנונות, הסקריפטים, האייקונים והנתונים לגלישה מהירה גם במצב טיסה או בעת ניתוק רשת.

## 🔐 מערכת הניהול (Admin Panel)

פאנל הניהול של האתר (`admin.html`) הוא Single Page Application עצמאי, מהיר ומאובטח המאפשר לצוות הישיבה לעדכן את כל נתוני האתר ללא צורך בידע טכני:

1. **אימות מאובטח ב-GitHub (Auth):**
   - התחברות באמצעות GitHub Personal Access Token.
   - שמירה מאובטחת ב-`sessionStorage` עם מחיקה אוטומטית בעת יציאה או סגירת הדפדפן.
2. **מנגנון שמירה בטוח למניעת התנגשויות (`putWithShaRetry`):**
   - ביצוע כתיבה ל-GitHub API תוך ניהול SHA מדויק.
   - מנגנון Retry אוטומטי במקרה של שגיאות קונפליקט (409/422), שליפה מחודשת של ה-SHA העדכני ושמירה חוזרת שקופה.
3. **ניהול חדשות וידיעות:**
   - יצירה, עריכה ומחיקה של כתבות.
   - עורך טקסט עשיר והעלאת תמונות ממוזערות המומרות אוטומטית ל-Base64.
4. **ניהול גלריה והעלאת תמונות מתקדמת:**
   - יצירת אלבומים חדשים, הוספת תמונות, עריכת כותרות ותאריכים.
   - העלאת תמונות מרובות במקביל באמצעות תור מנוהל (Batched Queue) בקבוצות של 3 למניעת חסימות רשת.
   - דחיסת תמונות מובנית בצד הלקוח (Client-side Image Compression) לפני ההעלאה.
   - הפקת קישורי CDN ישירים (`makeFilePublic`) המונעים חסימות סינון עתידיות.
5. **עורך הגדרות האתר (Site Editor):**
   - עריכת פרטי הישיבה, פסקאות "אודות", מספרי טלפון, קישורי תרומות וצבעי מותג ישירות מ-`data/site-config.json`.
6. **משלוח התראות פוש ישירות מהפאנל:**
   - הפעלת תהליך GitHub Actions מובנה לשליחת התראות לכל המנויים, ללא חשיפת מפתחות סודיים בדפדפן.
7. **תיבת פניות והודעות:**
   - סנכרון והצגת פניות מטופס יצירת הקשר (דרך Google Sheets API) עם סינון XSS קפדני.
8. **יומן פעולות מנהלים (Audit History):**
   - רישום אוטומטי של כל שינוי, העלאה ומחיקה בקובץ `data/history.json`.
9. **מערכת משימות פנימית (Tasks):**
   - ניהול משימות לצוות הישיבה (הוספה, סימון בוצע ומחיקה) הנשמרות ב-`data/tasks.json`.

## 🔍 אופטימיזציית SEO, Google ונראות בחיפוש

- **שם אתר רשמי ב-Google:** הטמעת סכמת `WebSite` תקנית (Schema.org JSON-LD) המגדירה את השם "ישיבת בית הלוי" ושמות חלופיים, יחד עם תגיות `og:site_name`, `application-name`, ו-`apple-mobile-web-app-title`.
- **תמונת תצוגה מרובעת לתוצאות החיפוש (1:1 Square Snippet):**  
  יצירת קובץ `assets/social-preview-square.png` (600x600 פיקסלים) המונע שוליים אפורים או עיוותים בכרטיס התוצאה של Google Search, ומשמש גם לתצוגה מקדימה עשירה ב-WhatsApp, Facebook ו-X (Twitter).
- **סכמת ReligiousOrganization מפורטת:** כוללת כתובת פיזית (חפץ חיים 6, ראש העין), קואורדינטות גיאוגרפיות (GeoCoordinates), קישור ל-Google Maps ופרטי התקשרות.
- **מפות אתר תקניות (Sitemaps) ו-Robots.txt:** כוללות הרחבת Google Image Sitemap (`xmlns:image`) לאינדוקס מהיר ומדויק של תמונת הישיבה הראשית.

## 🛠️ הוראות פיתוח והרצה מקומית

### דרישות קדם
- [Node.js](https://nodejs.org/) (גרסה 18 ומעלה)
- דפדפן אינטרנט מודרני

### התקנה והרצה
```bash
# 1. שכפול המאגר
git clone https://github.com/yt2178/Beit-Halevi.git
cd Beit-Halevi

# 2. התקנת תלויות הפיתוח (עבור בדיקות Jest)
npm install

# 3. הרצת כל בדיקות היחידה
npm test

# 4. הפעלת שרת מקומי (למשל באמצעות live-server או http-server)
npx serve .
```

### פריסה (Deployment)
הפריסה מתבצעת באופן אוטומטי ומיידי באמצעות **GitHub Pages**:
- כל שינוי שנדחף לענף `main` נפרס מיידית ללא צורך בשלבי Build מורכבים.
- גרסת האתר וה-Service Worker מנוטרות ומסונכרנות תמיד בין `index.html` ל-`sw.js`.
